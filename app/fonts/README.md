# IBM Plex local

Fuentes IBM Plex Sans y IBM Plex Mono, subconjunto latino (incluye español), servidas mediante `next/font/local`. Se conservaron los WOFF2 originales que ya servía la aplicación mediante `next/font/google`; no se modificaron los binarios. Sans es variable; Mono incluye los pesos 400, 500, 600 y 700.

Esto elimina las descargas de Google Fonts durante el build y mantiene la identidad tipográfica. Origen y licencia: [IBM Plex](https://github.com/IBM/plex), [SIL OFL 1.1](https://raw.githubusercontent.com/IBM/plex/master/LICENSE.txt). Véase `OFL.txt`.
